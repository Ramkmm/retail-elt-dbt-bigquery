# Retail ELT Pipeline using dbt, BigQuery, and Looker

This project demonstrates a modern ELT architecture using:

- **dbt** for transformation
- **BigQuery** as the data warehouse
- **Looker** for BI and visualization

## 🏗️ Structure

- `data/`: Raw CSVs (example only)
- `models/`: dbt models structured into staging, intermediate, and marts
